# Chapter 2 計算論モデリングの基礎

## Rescorla-Wagner モデル
古典的条件付け（パブロフ条件付け）の代表的なモデル
USとNSの対提示を続けた結果NSがCSになる
Rescorla-Wagner モデルはCSとUSの間の連合の強さ（連合強度）の変化を記述するモデル（Rescorla-Wagner, 1972）

CSとUSを1回づつ提示する（あるいは片方のみ）ことを1試行とし，t試行目におけるCS,USの連合強度を $V_t$ と表す。
### &emsp;&emsp;&emsp;&emsp; $V_{t+1} = V_t + \alpha(r_t - V_t)$ &emsp; (2.1)

$r_t$ は試行 $t$において得られたUSの強度を表す

ここではUSを報酬と考え，報酬が提示された場合は $r_t = 1$，そうでない場合は $r_t = 0$ とする
\alpha はパラメータであり，学習率と呼ばれる。1試行ごとの経験でどれだけ連合強度を更新するかを表す。
後で見ていくように，連動強度 $V_t$ はどのくらいのUS（報酬） $r_t$ が得られるかという「期待」あるいは「予測」を表すものと解釈できる。
よって，$(r_t - V_t)$ は**報酬予測誤差**と呼ばれる。\
$\delta_t = r_t -V_t$ &emsp; (2.3)
$V_{t+1} = V_t + \alpha \delta_t$ &emsp; (2.4)
とかける。

ここまでのモデルは主体が能動的に行動を選択するような要素はない。
以下，Q学習モデル，及びSARASAの特殊形のモデルの導入。

## 2腕バンディット課題
二つのスロットマシンの選択を繰り返すギャンブル課題。選択されたスロットマシンに割り当てられた報酬確率に従い報酬の有無が決定される。その報酬確率は主体には事前に知らされず，経験をもとにいずれがより報酬の得やすいスロットマシンであるかを判断する必要がある。
スロットマシンA,Bがある。それぞれを選択する行動を a = A, B と表す。
行動の価値を $Q(A)$ のように表す。\
$Q_{t+1}(a_t) = Q_t(a_t) + \alpha(r_t - Q_t(a_t))$ &emsp; (2.5)
試行 $t$ で選択された行動を $a_t$ とする。選択されなかった行動について基本的にQ学習モデルでは更新されない。
標準的なQ学習モデルでは選択確率 $P(a_t = A)$ を決定するためにソフトマックス関数を使用する。
ソフトマックス関数は以下の式で表される。\
$P(a_t = A) = exp(\beta Q_t(A)) / (exp(\beta Q_t(A)) + exp(\beta Q_t(B)))$ &emsp; (2.6)
ここで$\beta$ は逆温度と呼ばれるパラメータ.
変形すると，\
$P(a_t = A) = 1 / {1+exp(-\beta (Q_t(B) - Q_t(A)))}$  (2.7)
ここから試行 $t$ において選択肢Aを選ぶ確率 $P(a_t = A)$ の値は $Q_t(A)$ と $Q_t(B)$ の差とパラメータ $\beta$ で決まることがわかる

## パラメータ推定
実際の計算論モデリングでは行動 $a$ やその結果得られた報酬 $r$の系列がデータとして与えられ，そこから未知のパラメータである $\alpha$ や$\beta$ を推定する。
