# Rustを学ぶ
https://rust-lang.org/ja/learn/

Rustはまた、現代的な開発者向けツールをシステムプログラミングの世界にもたらしています。
- Cargo
    付属の依存関係管理ツール兼ビルドツールであるCargoは、依存関係の追加、コンパイル、管理を、Rustエコシステム全体で簡単かつ一貫したものにしています。
- rustfmt
    コード整形ツールであるrustfmtは、開発者間で一貫したコーディングスタイルを保証します。
- Rust Language Server
    Rust Language Serverは、コード補完やインラインのエラーメッセージなど、統合開発環境、つまりIDEとの連携を支えています。

Technology has come a long way.
→ テクノロジーは大きく進歩した。

incubation: 育成期間、準備期間、孵化、潜伏期間
startup incubation
→ スタートアップの育成

nascent: 生まれたばかりの、初期段階の、発展し始めた(まだ小さいけれど、これから成長しそうなものに使います)
a nascent industry
→ まだ始まったばかりの産業

enthusiasts: 熱心なファン、愛好家、支持者
AI enthusiasts
→ AI愛好家、AIに熱心な人たち

inevitable: 避けられない、必ず起こる、当然の成り行きの

turn heads: 注目を集める、人目を引く、振り向かせる
Her dress turned heads at the party.
→ 彼女のドレスはパーティーで注目を集めた。
The new product is turning heads.
→ その新製品は注目を集めている。

permeate: 広がる，浸透する，染み渡る
The smell of coffee permeated the room.
→ コーヒーの香りが部屋中に広がった。
Technology has permeated every aspect of our lives.
→ テクノロジーは私たちの生活のあらゆる面に浸透している。
A sense of anxiety permeated the office.
→ 不安な雰囲気がオフィス全体に漂っていた。

adoption: 採用、導入、受け入れ、養子縁組

vibrant: 活気のある、生き生きとした、鮮やかな
passionate: 情熱的な、熱心な、強い思いを持った

systems programming: システムプログラミング
OS、メモリ管理、低レベル処理、C/C++/Rust などに関わるプログラミング

prone to : ～しがちな、～になりやすい、～を起こしやすい
悪いこと・望ましくないことに使うことが多いです

elusive: つかみにくい、見つけにくい、理解しにくい、達成しにくい
何かが「手に入りそうで入らない」「はっきり捉えられない」イメージです。
an elusive bug
→ 見つけにくいバグ

concurrency
→ 並行性、同時実行性
concurrency bugs
→ 並行処理に関するバグ

crave: 強く欲しがる、切望する、無性に欲しくなる

brittle: もろい、壊れやすい、変更に弱い

delve: 深く掘り下げる、詳しく調べる(よく delve into ～ の形で使います。)
Let’s delve into the details.
→ 詳細を掘り下げて見てみましょう。

meticulous: 細かいところまで注意深い、非常に丁寧な、几帳面な
a meticulous plan
→ 綿密な計画
